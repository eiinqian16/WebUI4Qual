EZMesh

Mode Selection
Controller
The controller manages the entire network.
It coordinates communication between all connected agent nodes.
Make sure at least one controller is active before starting EZMesh.
Agent
The agent connects to a controller to extend network coverage.
Each agent receives instructions from the controller.
Ensure the agent is powered on and in range of the controller.


WPS Pairing
Start WPS pairing after completing EZMesh configuration for both controller and agent.
WPS should be pressed on both controller and agent sides.
Pairing will be done within 2 minutes. Check the wireless section to confirm the controller and agent connection.
